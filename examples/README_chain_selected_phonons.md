# Selected phonon modes in the chain transport benchmark

The selection also feeds `--static-epc-dm`, the complete static Gaussian EPC
response expansion. See [the static DM scheme](README_chain_static_epc_dm.md).

`chain_transport_alignment.py` accepts one shared wavevector, branch and weight
selection for static/dynamic SERTA, balanced RTA, full collision, snapshots,
snapshot curvature, moving-phonon TDSE and its periodic frequency-domain check.
Without the new flags, the previous full-mesh behavior is retained.

## Example

```powershell
python examples/chain_transport_alignment.py --grid 128 --qgrid 16 --supercell 4 --phonon-q 0.25 --phonon-branches 0 --phonon-weights 0.0625 --pairs 20 --fixed-centers --scale 0.125 --phonon-energy 0.02 --background 0.026 --delta 0.05 --omega 0.8 --tdse --tdse-trajectories 4 --output tmp/chain_selected_phonons
```

Add `--tdse-frequency-check` to compare TDSE with the existing periodic phonon
Liouville solver on identical sampled trajectories. Add `--curvature` for the
leading Gaussian snapshot correction without Monte Carlo noise. TDSE supports
positive optical frequencies; DC-only runs should omit `--tdse`.

The example above retains the q=1/4 and q=3/4 members of an original 16-point
quadrature, each with weight 1/16, and branch 0 only. Its total q weight is 1/8;
it is not a normalized two-point approximation to the complete phonon bath.

## CLI conventions

* `--phonon-q QX [QX ...]`: fractional reciprocal coordinates along the chain.
  The other two components are zero. Partners at -q modulo a reciprocal lattice
  vector are added automatically. Specifying both partners counts them once.
* `--phonon-branches NU [NU ...]`: zero-based primitive phonon branch indices.
  For this model, 0 is the A-atom x oscillator and 1 is the B-atom x oscillator.
  Omit the flag to retain both. These are pinned Einstein oscillators, not
  acoustic/optical eigenvectors. The branch list applies to every selected q.
* `--phonon-weights W [W ...]`: positive weights **per q point**, applied to each
  selected branch. One value is broadcast to every input q; otherwise supply
  one value per input q. An automatically inserted partner receives the same
  weight. Explicit conjugate partners must have equal weights. No normalization
  to unit total weight takes place.
* Omitted weights default to `1/qgrid`. Consequently, changing `--qgrid` while
  retaining a fixed selected pair changes its weight unless explicit weights
  are supplied. Use explicit weights to hold the restricted bath fixed during
  a convergence test.
* With branches or weights but no `--phonon-q`, selection starts from the full
  `--qgrid` mesh. A weight is not a probability over branch labels: all retained
  branches receive that q's weight, as in the original Brillouin-zone sum.

Selected points must be commensurate with both the electronic grid and the
supercell. For q=p/L, grid and supercell must accommodate the reduced denominator.
In explicit-q mode, qgrid itself need not divide grid: it only sets the default
weight. Supercell must still divide the primitive electronic grid. Invalid
branches, conjugate weights or commensurability fail before model construction.

At q=0 or q=1/2, the point is its own negative and is counted once. For a generic
pair, two independent real spatial quadratures (cosine and sine) are sampled.
Both positions and momenta are projected for TDSE. The same spatial projection
also applies to every temporal Fourier coefficient of the damped trajectory.

## Shared normalization and implementation

`system.phonons.PhononModeSelection` stores fractional 3D q vectors,
branches and absolute weights. The example attaches it to
`epc.phonon_model.modeSelection`. Self-energy and full collision consumers
read that selection automatically; they also accept an explicit
`phononSelection` argument. `ModelEPCLinewidth` includes selection contents in
its cache key. Existing explicit `qpoints/qweights` self-energy calls without
a selection retain their historical normalized-quadrature semantics.

The selector contains only quadrature and selection metadata, branch-range
checks, and mesh/supercell compatibility checks. It does not interpret branches
as atom/Cartesian directions or construct physical displacements.
`EinsteinPhonons` owns the local-oscillator covariance basis and projection
used below. Other phonon models must construct displacements from their own
frequencies and polarizations. Selection uses one branch list for all q points
and assumes matching conjugate branch labels at q and -q; it does not establish
that correspondence. This refactor does not add acoustic or force-constant
phonon models or a prescription for zero-frequency modes.

For cell-major independent local Gaussian displacements x_l with variance s²,
the selected displacement field is generated by filtering its discrete Fourier
components with amplitude sqrt(N*w_q). Thus

    <u_l u_l'> = s² sum_q w_q exp[2*pi*i*q.(R_l-R_l')]

for a selected atom/Cartesian branch. The paired sum is real. For a generic
pair, real covariance factors are sqrt(2*w_q)*s*cos(q.R_l) and
sqrt(2*w_q)*s*sin(q.R_l); a self-inverse point has one sqrt(w_q) factor.
Keeping a complete N-point mesh with w_q=1/N recovers the original independent
Einstein distribution, including the same seeded samples to roundoff.

Supercell construction carries the actual primitive cell origins and selection
into the phonon sampler. Build selected supercells directly from the primitive
model; nested selected-supercell construction is currently rejected. Primitive
q/branch selections in the frequency-domain EPC integrals are evaluated on the
primitive model, not reinterpreted as folded supercell branch labels.

Snapshot curvature contracts the full selected covariance using these real
normal-coordinate factors. Summing only independent local variances would miss
the cross-cell derivatives for a selected mode. `--curvature-step` still needs
finite-difference convergence. Snapshot curvature currently reports the moving-
center response, consistent with the original curvature option; the additional
`--fixed-centers` sampled snapshot output is the one appropriate for comparing
with the fixed-center TDSE Hamiltonian/current convention.

Results save `phonon_qpoints`, `phonon_qweights`, `phonon_branches` and snapshot
displacements in `results.npz`, plus the resolved selection in `metadata.json`.
TDSE metadata repeats that selection and reports `matches_main_phonon_bath`:
with explicit selection the bath can match even if qgrid and supercell differ.
The quantum and classical/Wigner statistics remain different approximations.

## Validation and physical interpretation

`tests/test_phonon_selection.py` checks:

* exact covariance against an independently projected complete white-noise basis;
* Fourier support and branch exclusion for snapshots and both trajectory types;
* generic-pair and self-inverse counting, and invalid input rejection;
* full-mesh recovery and mode-sector additivity of Fan, Debye-Waller and balanced
  transition rates;
* amplitude/rate scaling with absolute weights;
* all chain approaches sharing the selection, including identical TDSE and
  frequency-solver trajectories, and independence from auxiliary qgrid at fixed
  explicit q/weights.

This removes q integration from a restricted-bath comparison. It does not make
the full crystal conductivity equal to the sum of separate mode conductivities.
Born self-energies and rates add over independent modes; the final conductivity
generally requires solving with the combined collision operator. A few undamped
modes can also exhibit memory and coherent recurrence effects missing from a
Markov collision operator. The existing TDSE remains a prescribed classical or
Wigner harmonic bath, without quantum emission/absorption asymmetry or electron
backreaction. Wavevector selection does not change those approximations.

A numerical smoke run is saved in `tmp/chain_selected_q_steps128`: grid 32,
four-cell supercell, q=+/-1/4, branch 0, weight 1/16 per point, scale 0.125,
phonon energy 0.04 eV, background 0.026 eV, delta 0.05 eV, photon energy 0.8 eV,
four antithetic snapshot pairs and two Wigner TDSE trajectories. With 128 steps
per optical cycle, 16 background transient lifetimes, at least one measured
phonon cycle and 17 Fourier phase points, the TDSE EPC correction is
approximately 0.444102 + 0.873349i S/m. Its difference from the matched
finite-window frequency-domain EPC correction is -4.171e-5 - 7.767e-5i S/m
(about 0.009% of that correction). This validates the shared selected trajectory
path numerically; the small electronic grid and ensemble are not a converged
thermal-transport benchmark and do not establish agreement with quantum SERTA.
